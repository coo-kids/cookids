# Vue and Vite for Cookids

Keep product prices and editable text out of Vue components: consume the typed exports from `@cookids/content` and catalog-only exports from `@cookids/domain`.

Keep components focused; extract shared utilities and preserve accessible keyboard and focus behavior. Do not import the server-wide domain entrypoint into the browser bundle.

Consult [the Vue reference](references/vue.llms.txt.md) and [the Vite reference](references/vite.llms.txt.md) for framework behavior.
